# Testing Quantum Gravity with LIGO Data

This repository contains my independent research project on quantum black holes, submitted to the Ulysses Young Explorers in Science (UYES) journal.

## About the Project
I analyzed open gravitational-wave data from the LIGO observatory (event GW150914) using Python. I searched for "echoes" and quasinormal mode (QNM) frequencies to test three models of quantum gravity: Loop Quantum Gravity (LQG), Asymptotic Safety (ASG), and String Theory.

## Files in this Repository
*   `Anna_Gavrilova...pdf` — The full research paper.
*   `Quantum_Black_Holes_Code.ipynb` — The Python code used for data analysis in Google Colab.
